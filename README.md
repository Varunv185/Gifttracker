# 🎁 GiftPool - Split • Settle • Celebrate

GiftPool is a modern, real-time financial tracking and debt-splitting web application designed for group gifts, trips, and shared celebrations. Built with vanilla web technologies and powered by Firebase cloud infrastructure.

## 🌐 Live Demo
* **Production App**: [https://gifttracker-82492.web.app](https://gifttracker-82492.web.app)[cite: 3]
* **GitHub Repository**: [https://github.com/Varunv185/Gifttracker](https://github.com/Varunv185/Gifttracker)[cite: 3]

## ✨ Key Features

- **Real-Time Firebase Sync**: Instant data synchronization across multiple devices and users via Cloud Firestore.
- **Mobile-Responsive UI**: Features a sleek, slide-out drawer menu, compact mobile layout, and custom backdrop overlays for mobile viewports.
- **Smart Budget Tracking**: Dynamic progress bars and live financial metrics comparing collected funds against variable target budgets[cite: 3].
- **Optimized Settlement Engine**: Automatically computes the minimum number of peer-to-peer transactions required to settle group debts[cite: 3].
- **Instant UPI & QR Code Integration**: Generates deep links and QR codes for seamless payments via GPay, PhonePe, or Paytm[cite: 3].
- **Smart Data Importer**: Paste raw text lists (e.g., "Alice, 1000\nBob 500") to automatically parse and import participant entries[cite: 3].
- **Excel/CSV Export**: Export detailed contribution reports and settlement summaries instantly[cite: 3].
- **Secure Authentication**: Supports Google Sign-In and Email/Password credential authentication via Firebase Auth[cite: 3].

## 🛠️ Technology Stack

- **Frontend**: HTML5, Modern CSS3 (with CSS Variables & Dark/Light Theme support), Vanilla JavaScript (ES6+ Modules)[cite: 3]
