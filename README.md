# 🎁 GiftPool - Split • Settle • Celebrate

GiftPool is a modern, real-time financial tracking and debt-splitting web application designed for group gifts, trips, and shared celebrations. Built with vanilla web technologies and powered by Firebase cloud infrastructure.

## ✨ Key Features

- **Real-Time Firebase Sync**: Instant updates across devices using Cloud Firestore.
- **Smart Budget & Progress Tracking**: Dynamic progress bars and metrics showing collected funds vs. target budgets.
- **Optimized Settlement Engine**: Automatically calculates the minimum number of peer-to-peer transactions required to settle debts[cite: 3].
- **Instant UPI & QR Code Integration**: Generates direct deep links and QR codes for seamless payments via GPay, PhonePe, or Paytm[cite: 3].
- **Smart Data Importer**: Paste messy text lists (e.g., "Alice, 1000\nBob 500") to automatically clean, parse, and import participant data[cite: 3].
- **Excel/CSV Export**: Export detailed contribution and settlement reports with a single click[cite: 3].
- **Secure Authentication**: Support for Google Sign-In and Email/Password authentication via Firebase Auth[cite: 3].
- **Pool Library Management**: Create, switch between, and manage multiple unique gift pools[cite: 3].

## 🛠️ Technology Stack

- **Frontend**: HTML5, Modern CSS3 (with CSS Variables & Dark/Light Theme support), JavaScript (ES6+ Modules)
- **Backend & Database**: Firebase Cloud Firestore
- **Authentication**: Firebase Auth (Google Provider & Email/Password)
- **Hosting**: Firebase Hosting / Vercel
